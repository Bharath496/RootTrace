RootTrace is a local-first CI failure intelligence engine that classifies failures, fingerprints recurring problems, detects flaky tests, correlates Git changes, analyzes code impact, and ranks probable root causes without sending proprietary engineering data to a hosted service.

One investigation layer.

RootTrace turns heterogeneous CI and test output into normalized evidence that engineers can inspect locally.

Multi-framework parsing

pytest, JUnit XML, Jest, Maven/Gradle, generic CI logs, plus parser plugins.

Failure fingerprints

Normalize volatile values and group recurring failure signatures across runs.

Flaky-test history

Track pass/fail outcomes and surface tests that alternate across recorded executions.

Git correlation

Compare failures with changed files, stack paths, branches, commits, and recent file history.

Change impact

Build a lightweight dependency graph for Python, JavaScript/TypeScript, and Java.

Explainable ranking

Rank probable causes with visible evidence rather than hiding decisions behind an opaque model.

Zero-budget quick start.

No RootTrace account, paid API, hosted database, or cloud analyzer is required.

git clone https://github.com/Bharath496/RootTrace.git
cd RootTrace
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
# source .venv/bin/activate

python -m pip install -e .
roottrace init
roottrace doctor
roottrace analyze tests/fixtures/pytest_failure.log
roottrace impact
roottrace report

Local by default.

Your logs stay yours.

Core analysis is designed to make no network calls. State is stored in a local SQLite database under .roottrace/, which is gitignored by default.

AI is optional.

The deterministic analysis pipeline does not require an LLM. An optional locally installed Ollama model can explain recorded evidence without being the source of truth.
