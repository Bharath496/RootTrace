# RootTrace 1.0 Product Scope

RootTrace 1.0 is the first complete usable product boundary, not the end of the possible product.

## In scope

- local CLI product;
- multi-framework artifact parsing;
- local history and recurrence;
- flaky-test evidence;
- Git/change correlation;
- lightweight static impact analysis;
- explainable root-cause ranking;
- portable reports;
- major-CI integration examples;
- parser plugins;
- local benchmark harness;
- optional local-model explanation.

## Deliberately not claimed as complete

- perfect causal inference;
- hosted organization dashboards;
- enterprise SSO/RBAC;
- every language/build system;
- distributed tracing ingestion;
- IDE extensions;
- automatic test skipping in production pipelines;
- automatic code changes/fixes;
- proprietary CI vendor APIs.

Those are future product directions, not missing pieces required to use V1.
